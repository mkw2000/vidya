Overview

Vidya is a clean, distraction-free native desktop application for downloading videos and audio from YouTube and thousands of supported websites. Built directly in C with Raylib, it delivers instant startup times and low resource usage without Electron or web framework overhead.

Key Features

  • Bundled yt-dlp, ffmpeg, and ffprobe binaries out of the box
  • Multi-resolution video downloading (1080p, 720p, 480p, or maximum available quality)
  • High-quality audio extraction (MP3, M4A, FLAC, WAV, OPUS)
  • Support for subtitle downloads, thumbnail embedding, and metadata tags
  • Customizable output destination folders and output filename templates
~~~

Compilation

To compile the macOS bundle locally from source:

git clone https://github.com/your-username/vidya.git
cd vidya/ytdlp-gui
brew install raylib pkg-config
make macos-app
~~~
